# Phase 1 Data Model: Персональный лендинг-визитка

Все сущности этой фичи — **статичные frontend-конфиги** (слой `entities` во Feature-Sliced Design), а не
таблицы базы данных (см. `research.md`, п.6, и Assumptions в `spec.md`). Ниже описаны TypeScript-типы и
структура конфигов.

## Profile (`entities/profile`)

Представляет владельца визитки, используется hero-блоком и блоком навыков.

| Поле           | Тип                             | Обязательность | Описание                                               |
| -------------- | ------------------------------- | -------------- | ------------------------------------------------------ |
| `firstName`    | `string`                        | обязательное   | Имя ("Руслан")                                         |
| `lastName`     | `string`                        | обязательное   | Фамилия ("Буданов")                                    |
| `profession`   | `string`                        | обязательное   | Профессия/подпись под именем ("Fullstack-разработчик") |
| `photoUrl`     | `string` (import-путь к ассету) | обязательное   | Фотография для hero-блока                              |
| `photoAlt`     | `string`                        | обязательное   | Alt-текст фотографии (доступность)                     |
| `contactLabel` | `string`                        | обязательное   | Текст кнопки-заглушки "контакты" в hero-блоке (FR-015) |

**Validation rules**: все поля непустые строки; `photoUrl` — валидный статический импорт/URL, не `undefined`
(Edge case: если фото не загрузилось — фото-колонка полностью скрывается на уровне UI-компонента, текстовый
блок остаётся по центру; обрабатывается на уровне UI, а не на уровне данных).

**Примечание**: тексты об опыте и стеке технологий ("Опыт более 3-ех лет...", "Мой стек технологий: ...")
фактически хранятся в `entities/skill` (поле `SkillsContent.summary`), а не в `Profile` — используются
блоком навыков, не hero-блоком.

## Skill (`entities/skill`)

Единица стека технологий, отображается списком с иконками в блоке навыков.

| Поле    | Тип                                                           | Обязательность | Описание                                   |
| ------- | ------------------------------------------------------------- | -------------- | ------------------------------------------ |
| `id`    | `string`                                                      | обязательное   | Уникальный ключ (например, `"typescript"`) |
| `label` | `string`                                                      | обязательное   | Отображаемое название ("TypeScript")       |
| `Icon`  | ссылка на react-icons компонент (`IconType` из `react-icons`) | обязательное   | Иконка-логотип технологии                  |

**Validation rules**: `id` уникален в пределах списка; минимальный набор на старте — Javascript, TypeScript,
React, Nest.js (FR-006).

**State**: список — упорядоченный массив `Skill[]`; порядок в массиве определяет порядок отображения.

## Project (`entities/project`)

Карточка портфолио в блоке проектов.

| Поле            | Тип              | Обязательность                     | Описание                                                       |
| --------------- | ---------------- | ---------------------------------- | -------------------------------------------------------------- |
| `id`            | `string`         | обязательное                       | Уникальный ключ карточки                                       |
| `title`         | `string`         | обязательное                       | Название проекта ("Навигатор Химии")                           |
| `description`   | `string`         | обязательное                       | Краткое описание проекта                                       |
| `url`           | `string \| null` | опциональное (`null` для заглушки) | Внешняя ссылка; `null` означает карточку-заглушку без перехода |
| `isPlaceholder` | `boolean`        | обязательное                       | `true` для карточки "Список будет дополняться"                 |

**Validation rules**: если `isPlaceholder === false`, то `url` ДОЛЖЕН быть непустой валидной внешней ссылкой,
открываемой с `target="_blank"` и `rel="noopener noreferrer"` (FR-007); если `isPlaceholder === true`, `url`
равен `null` и карточка не кликабельна.

**State**: список — упорядоченный массив `Project[]`, минимум одна реальная карточка ("Навигатор Химии") и одна
карточка-заглушка (FR-008, FR-009).

## VisitCounter (`entities/visit-counter`)

Заглушка счётчика посещений.

| Поле    | Тип      | Обязательность | Описание                                           |
| ------- | -------- | -------------- | -------------------------------------------------- |
| `value` | `number` | обязательное   | Статичное отображаемое значение (FR-010)           |
| `label` | `string` | обязательное   | Подпись рядом со значением (например, "Посещений") |

**Validation rules**: `value` — целое неотрицательное число; на этом этапе не связано с реальным источником
данных (Assumptions).

**Relationships**: сущности независимы друг от друга; все four сущности потребляются исключительно на уровне
`widgets` (hero, skills, projects, visit-counter) и не пересекаются между собой.
