# Quickstart: Персональный лендинг-визитка

## Prerequisites

- Docker + Docker Compose установлены
- Node.js LTS и pnpm — только если запускать пакеты локально без Docker (опционально, для быстрой разработки
  фронтенда с HMR вне контейнера)

## Запуск полного стека

```bash
docker compose up
```

Поднимает три сервиса согласно конституции (принцип IX): `frontend`, `backend`, `postgres`.

## Валидация: лендинг открывается и содержит все блоки

1. Открыть `http://localhost:<frontend-port>` в браузере.
2. **Ожидаемо**: без прокрутки видны имя "Руслан Буданов", подпись "Fullstack-разработчик" и фотография
   (User Story 1, SC-001).
3. Прокрутить вниз — видны текст об опыте/месте работы и список технологий с иконками (User Story 2).
4. Прокрутить дальше — видны карточка "Навигатор Химии" (с рабочей ссылкой, открывающейся в новой вкладке) и
   карточка-заглушка "Список будет дополняться" (User Story 3).
5. В конце страницы — блок счётчика посещений со статичным числом.

## Валидация: адаптивность

1. В DevTools браузера включить эмуляцию мобильного устройства (ширина ≤ 375px).
2. **Ожидаемо**: нет горизонтальной прокрутки, hero-блок перестраивается в вертикальную компоновку, весь текст
   читаем (SC-004).

## Валидация: данные вынесены в конфиги (FR-011, SC-002)

1. Изменить значение в `apps/frontend/src/entities/profile/config.ts` (например, `role`) без правки
   компонентов `widgets/hero`.
2. Перезапустить/дождаться HMR фронтенда.
3. **Ожидаемо**: изменение отражается на странице без правок кода компонентов представления.

## Валидация: health-check

```bash
curl -i http://localhost:<backend-port>/health
```

**Ожидаемо**: `HTTP/1.1 200 OK`, тело `{"status":"ok"}` — см. `contracts/health-rest.md`.

## Валидация: GraphQL-заглушка

Открыть GraphQL playground/`/graphql` backend'а (если включён в dev-режиме) и выполнить:

```graphql
query {
  ping
}
```

**Ожидаемо**: ответ `{ "data": { "ping": "ok" } }` — см. `contracts/graphql-stub.md`. Никаких доменных
query/mutation в схеме на этом этапе быть не должно.
